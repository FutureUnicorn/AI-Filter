# Contributing to AI-Filter

All human and AI-assisted contributions follow `docs/engineering/delivery-workflow.md` (AF-DELIVERY-1.0), `docs/PRODUCT_BOUNDARY.md`, and `docs/engineering/ci.md`.

Start from current `origin/develop`, read the complete Jira issue and dependencies, and map each acceptance criterion to implementation and verification evidence. Use `.github/pull_request_template.md` for every pull request. A named human owns the evidence and remains responsible for review accuracy even when an AI assistant helped write code or documentation.

Project-level assistant guidance lives in this repository. Contributors do not need personal assistant configuration to follow the delivery process.
