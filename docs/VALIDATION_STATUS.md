## Hard floors (do not loosen these to keep momentum)

- Candidate proof-step completion below 60% → stop and redesign, not "mixed but okay."
- Evidence-citation precision below 98% on a live pilot → fix the extraction/validation workflow before running another pilot.
- Any material candidate-data incident → pause all new processing until containment, root-cause remediation, and corrective testing are complete.
